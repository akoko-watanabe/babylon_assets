ROBOT CELL LAYOUT — FULL PLACEMENT SPECIFICATION

単一多関節ロボットのピック&プレイス自動配置 仕様

2架台タイプ判定

テーブル架台

天板があるため、P・Qが架台内に収まるかを次ステップで判定する。収まる場合はテーブル不要。

キャスター架台

天板を持たない前提のため、常に「両方テーブル」パターンがデフォルトになる。架台自体はロボット搭載のみのミニマム構成。

3架台内オフセット探索(位置の決め方)

P・Qはロボット相対オフセットとして既に固定されているため、自由度は「架台上でロボットをどこに据えるか」という並進のみ。各領域について区間制約を立て、共通部分を配置可能領域とする。

m ≤ x_r + dPx_min (Pの左端が架台内) x_r + dPx_max ≤ Ws − m (Pの右端が架台内) → x_r ∈ [ m − dPx_min , Ws − m − dPx_max ] ※ y方向・Q領域についても同様の区間を求め、全区間の共通部分を採る

共通部分が空でない→その中心(または安全側に寄せた点)にロボットを配置。空→架台に収まらないと判定し、次ステップの分岐へ。

4収容パターンの分岐

両方収まる

P・Q双方の区間に共通部分あり。その中心にロボットを配置。架台の向きは、P&Q外接矩形の長辺がX軸寄りかY軸寄りかで0°/90°に丸める。テーブル不要。

片方だけ収まる

収まる方の区間内で、収まらない方のfootprintが架台と完全分離できる部分区間を優先して選ぶ(次節)。収まらない方はテーブル化。

両方テーブル

架台はロボット搭載のみのミニマム構成。P・Qともに外部テーブルへ。キャスター架台は基本このパターン。

straddle(境界またぎ)

どうオフセットをずらしても領域が架台境界をまたぐ=区間が空。テーブルは架台と重なる前提とし、人手確認フラグを立てる(9節)。

5片方だけ収まる場合の優先順位(位置の微調整)

  1. Tier 1(必須):収まる方の区間内にロボット位置を収める
  2. Tier 2(できれば):その区間内で、テーブル化する方が架台と重ならない部分区間があれば採用
  3. Tier 3(フォールバック):Tier2不可なら区間内で重なりが最小になる端を採用し、straddle警告として人手確認へ

すべて区間の共通部分・端点の比較という閉形式の計算で完結し、反復探索(最適化)は発生しない。

6テーブルの角度決定(回転角の決め方)

テーブルの向きはX軸に平行(水平)または垂直の2択のみ。架台の向きも同様に軸整列限定。

Δx = |x_region − x_stand|, Δy = |y_region − y_stand| Δx > Δy → 垂直配置(長辺∥Y軸、短辺が架台側=X方向を向く) Δx ≤ Δy → 水平配置(長辺∥X軸、短辺がY方向を向く)
  1. 収容可否(領域がテーブル内に収まるか)で先に足切り
  2. 両方の向きで収まる場合のみ、Δx/Δyルールで最終決定
  3. 片方でしか収まらない場合はその向きを無条件に採用

7スライド可能範囲と干渉チェック

テーブルは対象領域より一回り大きいため、領域を内包したままテーブル中心を動かせる「スライド可能範囲(区間)」がある。この区間から、干渉しうる相手(架台・他テーブル)と重なる部分を穴として差し引き、残った区間から位置を選ぶ。

複数の空き区間が残った場合は「一番広い区間」「架台に近い方」などの単純な基準で選択する。この区間がそもそも空(=テーブル寸法が領域より小さい)なら、寸法不足のエラーとして扱う。

8ピック/プレイスどちらを架台に残すか

両方個別には収まるが同時には収まらない場合の優先順位の目安。

  • 専用治具・位置決めフィクスチャが必要な側を架台側に残す(精度確保)
  • 面積が小さい側を架台側に残す
  • 経験則として、ピック側(供給・位置決め精度重視)は架台上、プレイス側(パレット・コンベア等で面積が大きくなりがち)はテーブル/外部設備になる傾向がある。ただし絶対則ではなく、上記2点の個別判定を優先する

9straddle(境界またぎ)ケースの扱い

領域が架台境界をまたいでおり、どうオフセットをずらしても全体を架台内に収められない場合。テーブルは領域全体をカバーする必要があるため、架台と物理的に重なるのは避けられない。

  1. まず単体領域での区間探索を必ず試す(パターン1の可能性を潰す)
  2. それでも配置可能領域が空 →「straddleフラグ」を明示的に立て、自動調整ループの対象から外して人手確認へ
  3. 人手修正の選択肢のヒント:天板高さを揃えて隣接させる/架台サイズを見直す/ロボット搭載位置の上流見直し
